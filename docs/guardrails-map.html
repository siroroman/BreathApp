Guardrails map

Guardrails are automatic barriers that catch a mistake by an agent or a person before it reaches main. The map follows one change on its way: from a Claude session on your Mac to the repo settings on GitHub. Status as of 6 November 2026, from the repo and the GitHub settings.

The gate in front of main is solid, and your disk now follows it. main can only be reached through a pull request with six green checks, and GitHub rejects a push that contains a key or a token. On disk the git hooks refuse a commit on and a push to main, and the Claude hook blocks skipping them. What is left: make setup has to be run once per clone, and a person at a terminal can still skip a hook.
