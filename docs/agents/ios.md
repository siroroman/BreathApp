# iOS

## Layout

| Path | What |
|---|---|
| `project.yml` | XcodeGen spec, the only source of truth for the Xcode project. `Breathnest.xcodeproj` is generated by `make gen` and git-ignored: never edit or commit it. |
| `App/Breathnest/` | App target: SwiftUI views, ticker, Core Haptics adapter, screen-awake and scene-phase handling. |
| `App/BreathnestTests/` | App unit tests (run on the simulator). |
| `BreathnestKit/` | Local Swift package, Foundation only. Domain logic: see [ADR 0001](../adr/0001-domain-logic-in-a-ui-free-swift-package.md). |

Product name Breathnest, bundle ID `com.siroroman.breathnest`, iPhone only (`TARGETED_DEVICE_FAMILY: 1`), deployment target iOS 26.0, Swift 6 language mode. Add a file under `App/` or `BreathnestKit/` and run `make gen` (the build targets do it); a new target, setting or package goes into `project.yml`.

## Simulator per worktree

`scripts/simulator.sh` owns the simulator, the Makefile calls it.

- The template is a simulator named **`Breathnest`** (iPhone 17 Pro, iOS 26.2). It is created on first use.
- The main checkout uses the template itself. Every linked worktree gets a clone named **`Breathnest-<worktree folder>`**, made with `simctl clone`, so parallel sessions never fight over one running device.
- `make run` boots this checkout's simulator; `scripts/simulator.sh` prints its UDID. Always pass the UDID, never `booted`, because several simulators may be running.
- Delete a clone together with its worktree: `xcrun simctl delete "Breathnest-<folder>"`.
- To test on another OS version, change `RUNTIME` in `scripts/simulator.sh`, not the Makefile.

## Conventions

- Logic goes into `BreathnestKit` first, with a test. The app only draws it and talks to the system. If a type needs `UIKit`, `SwiftUI` or `CoreHaptics`, it belongs in the app target.
- SwiftUI with `@Observable` models, no Combine, no `ObservableObject`. Follow the `swiftui-expert-skill` for state, lists and Liquid Glass.
- Swift Concurrency: `async`/`await` and actors, no completion handlers or `DispatchQueue`. UI types are `@MainActor`. Follow the `swift-concurrency-pro` skill. Code in the Kit is `Sendable` value types where it can be.
- Time comes from an injected `Clock`, never `Date()` or `Task.sleep` called directly in logic (see [testing](testing.md)).
- User-visible text lives in the String Catalog, not in the Kit and not as string literals in logic.
- Use the glossary terms in type and test names (`Exercise`, `Pattern`, `Phase`, `Cycle`, `Session`, `Breath level`).
- No third-party dependencies without a decision recorded in an ADR.
